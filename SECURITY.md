# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Proofly, please do **NOT** open a public issue.

Instead, please send an email to the project maintainers or report it privately via GitHub Security Advisories.

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact and tenant isolation boundaries affected.

We will acknowledge receipt within 48 hours and work on a fix promptly.
